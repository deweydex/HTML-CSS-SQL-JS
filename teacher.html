Part 1: HTML Basics

Getting started

Read an example, then try it. Whenever you wonder "what would happen if I changed this?", change it and see. That question is most of how programmers learn.

🎯 Teaching Tips - HTML Section

💡 Recommended Approach
  • Start with viewing source: Have students right-click this page and "View Page Source" to see HTML in action
  • Semantic HTML: Emphasise that tags have meaning, not just appearance
  • Nesting analogy: Use Russian dolls or boxes-within-boxes as an analogy
  • Live demo: Open DevTools (F12) and modify HTML in real-time
⚠️ Common Student Mistakes
  • Forgetting closing tags: <p>Text instead of <p>Text</p>
  • Improper nesting: <p><div></p></div> (wrong!) vs <div><p></p></div> (correct!)
  • Case sensitivity confusion: HTML tags are case-insensitive, but lowercase is standard
  • Missing quotes in attributes: href=page.html should be href="page.html"

What is HTML?

HTML (HyperText Markup Language) is the standard language for creating web pages. It uses tags to structure content.

HTML Structure Example:

<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is a paragraph.</p>
</body>
</html>

Common HTML Tags:

  • <h1> to <h6> - Headings (h1 largest, h6 smallest)
  • <p> - Paragraph
  • <a href="url"> - Link
  • <img src="image.jpg" alt="description"> - Image
  • <div> - Container/division
  • <span> - Inline container
  • <ul> and <li> - Unordered list
  • <table>, <tr>, <td> - Table elements

Part 2: CSS Styling

Getting started

You can change the CSS of any web page, including this one. Right-click something on the page and choose Inspect. The panel that opens is the browser's DevTools (developer tools), and it shows the CSS for whatever you clicked. Click a value, such as a colour, and type a new one. Nothing you change there is saved, so experiment freely: refreshing the page puts everything back.

🎯 Teaching Tips - CSS Section

💡 Recommended Approach
  • Use browser DevTools: Show students how to modify CSS live in the Elements panel
  • Specificity confusion: Explain with concrete examples (inline > ID > class > element)
  • Box model first: This is the foundation - spend extra time here
  • Colour theory: Discuss hex codes, RGB, and named colours
  • Responsive design: Open DevTools device mode to show mobile vs desktop
⚠️ Common Student Mistakes
  • Missing semicolons: color: blue works, but color: blue color: red breaks
  • Wrong selector syntax: .class needs the dot, #id needs the hash
  • Margin vs padding confusion: Use the box model visual repeatedly!
  • Forgetting units: width: 100 doesn't work, need width: 100px
  • Colour typos: #fff is white, #000 is black (backwards from intuition!)

What is CSS?

CSS (Cascading Style Sheets) controls how HTML elements look on the page: colours, fonts, layouts, and more.

A spelling note: CSS uses American spelling, so the property is color, never colour. If you write colour: red; the browser quietly ignores it. No error, just nothing happens.

Three Ways to Add CSS:

  1. Inline: <p style="color: blue;">Text</p>
  2. Internal: In <style> tags within <head>
  3. External: Separate .css file (Best practice!)

CSS Syntax:

selector {
    property: value;
    another-property: value;
}

/* Example: */
p {
    color: blue;
    font-size: 16px;
    margin: 10px;
}

CSS Selectors

  • element - Selects all elements of that type (e.g., p)
  • .class - Selects elements with that class (e.g., .highlight)
  • #id - Selects element with that ID (e.g., #header)
  • element.class - Combines selectors (e.g., p.intro)

Try It: Restyle This Page

The Appearance button (top right, or bottom right on a phone) changes how this page looks. Open it, switch to the dark theme, then try a different font or a bigger text size.

The HTML stays exactly the same when you do this. The page keeps its colours and sizes in CSS variables: values with a name, such as --bg for the background colour. The Appearance panel swaps in a different set of values. Here is a small piece of this page's own styles.css:

:root {
    --bg: #f5f7fa;
    --fg: #1f2933;
}

:root[data-theme="dark"] {
    --bg: #12151c;
    --fg: #e6e8eb;
}

body {
    background-color: var(--bg);
    color: var(--fg);
}

Something to notice: the body rule never mentions dark mode. It only asks for var(--bg). Which rule decides what --bg is, and when?

💡 On the projector

Open Appearance and raise the text size before class so the back row can read the page. The same panel is a ready-made demonstration for this section: switch the theme live and ask what changed in the HTML (nothing) and what changed in the CSS (only the variables).

Part 3: SQL Database Queries

Getting started

Read the commands first, or jump straight to the playground and click an example query. Both work.

Remember: This database resets when you refresh the page, so feel free to experiment. You cannot break anything permanently. Mistakes are learning opportunities!

🎯 Teaching Tips - SQL Section

💡 Recommended Approach
  • Start with SELECT *: Let students see all data before filtering
  • Build complexity gradually: SELECT → WHERE → ORDER BY → Aggregate functions
  • Real-world examples: Relate queries to social media (finding friends), shopping (searching products)
  • Error messages are teachers: Encourage reading SQL errors carefully
  • SQL is forgiving: Case-insensitive, whitespace-flexible (but teach conventions!)
  • Safety first: Always use WHERE with UPDATE/DELETE (teach disaster avoidance!)
⚠️ Common Student Mistakes
  • Forgetting semicolons: Not required in this browser environment, but good practice
  • UPDATE/DELETE without WHERE: "I updated ALL the records!" - Teach paranoia
  • Comparison operators: Confusing = (equals) with == or !=
  • String quotes: SQL uses single quotes for strings: 'Alice' not "Alice"
  • Column names in WHERE: Forgetting table columns exist: WHERE age > 18 not WHERE student.age > 18
  • ORDER BY direction: Forgetting ASC/DESC (defaults to ASC)

What is SQL?

SQL (Structured Query Language) is used to manage and query databases. It lets you store, retrieve, update, and delete data.

  • students - Contains student information (id, name, age, grade)
  • courses - Contains course information (id, name, instructor, credits)

Basic SQL Commands

SELECT - Retrieve Data

SELECT column1, column2 FROM table_name;

Gets data from a table. Use * to select all columns.

WHERE - Filter Results

SELECT * FROM students WHERE age > 20;

Keeps only the rows that match a condition. Try it: only three of the eight students are over 20.

ORDER BY - Sort Results

SELECT * FROM students ORDER BY name ASC;

Sorts results. Use ASC (ascending) or DESC (descending).

INSERT - Add New Data

INSERT INTO students (name, age, grade) 
VALUES ('John', 20, 85);

Adds new rows to a table.

UPDATE - Modify Data

UPDATE students SET grade = 90 
WHERE name = 'John';

Changes existing data. Always use WHERE!

DELETE - Remove Data

DELETE FROM students WHERE id = 5;

Removes rows from a table. Use carefully!

Practice Exercises

These exercises progress from simple to complex. You can:

  • Work through them in order to build skills progressively
  • Choose exercises that match your current comfort level
  • Use hints when stuck, but try on your own first
  • Come back to challenging exercises after completing easier ones

Learning Tip: If you get an error, read it carefully. SQL error messages often tell you exactly what's wrong.

Exercise 1: Basic SELECT

Select only the name and age columns from the students table.

Show Hint

Use: SELECT column1, column2 FROM table_name;

✅ Solution:
SELECT name, age FROM students;

Expected Result: A table showing all students' names and ages (8 rows)

Teaching Note: Emphasise that * selects all columns, but naming specific columns is more efficient and clearer.

Exercise 2: WHERE Clause

Find all students whose grade is less than 75.

Show Hint

Use the WHERE clause with the < operator.

✅ Solution:
SELECT * FROM students WHERE grade < 75;

Expected Result: Frank Miller (grade 73)

Teaching Note: Discuss comparison operators: =, !=, <, >, <=, >=

Extension: Ask students to find all students with grades between 75 and 85: WHERE grade >= 75 AND grade <= 85

Exercise 3: INSERT

Add yourself as a new student to the database!

Show Hint

Start with INSERT INTO students (name, age, grade) VALUES (...); Text goes inside quotes, numbers don't. You don't need to give an id.

✅ Solution:
INSERT INTO students (name, age, grade) VALUES ('Your Name', 20, 85);

Verification: Run SELECT * FROM students; to see the new student

Teaching Note: The id column auto-increments, so students don't need to provide it.

Common Error: Students forget quotes around strings. Numbers don't need quotes, but text does!

Exercise 4: Sorting

Show all students sorted by name in alphabetical order.

Show Hint

Use ORDER BY with ASC for ascending order.

✅ Solution:
SELECT * FROM students ORDER BY name ASC;

Note: ASC is default, so ORDER BY name also works

Teaching Note: Show DESC for reverse order. Discuss multiple sort keys: ORDER BY grade DESC, name ASC

Exercise 5: COUNT Function

How many courses are in the database?

Show Hint

Use: SELECT COUNT(*) FROM table_name;

✅ Solution:
SELECT COUNT(*) FROM courses;

Better version with alias:

SELECT COUNT(*) AS total_courses FROM courses;

Expected Result: 5 courses

Teaching Note: Introduce other aggregate functions: SUM(), AVG(), MAX(), MIN()

🌟 Bonus Exercises (Advanced Students)

Exercise 6: UPDATE

Challenge: Give all students with grades below 75 a 5-point bonus.

UPDATE students SET grade = grade + 5 WHERE grade < 75;

Verification: Check Frank Miller's grade increased from 73 to 78

Exercise 7: DELETE

Challenge: Remove all students under age 20.

DELETE FROM students WHERE age < 20;

Warning: This permanently removes data! Emphasise the importance of WHERE clause.

Exercise 8: Complex Query

Challenge: Find students aged 20 or 21 with grades above 85, sorted by grade descending.

SELECT * FROM students 
WHERE (age = 20 OR age = 21) AND grade > 85 
ORDER BY grade DESC;

Expected Result: Henry Moore (94), Grace Wilson (89), Alice Johnson (88). Eve Davis is 22, and David Brown has exactly 85, so neither qualifies.

Exercise 9: Aggregate with WHERE

Challenge: What's the average grade of students aged 20?

SELECT AVG(grade) AS average_grade FROM students WHERE age = 20;

Expected Result: Average of Alice (88), David (85), Henry (94) = 89

Exercise 10: Multiple Tables

Challenge: Find all 4-credit courses.

SELECT * FROM courses WHERE credits = 4;

Expected Result: Introduction to Programming, Database Systems

Future Topic: This is a setup for teaching JOINs later (which students aren't enrolled in courses?)

📚 Teaching Notes & Strategies

🎯 Learning Objectives

By the end of this tutorial, students should be able to:

  1. Explain the purpose and structure of HTML documents
  2. Create properly nested HTML elements with appropriate attributes
  3. Apply CSS styles using different selector types
  4. Understand and visualize the CSS box model
  5. Write basic SQL queries (SELECT, INSERT, UPDATE, DELETE)
  6. Filter and sort data using WHERE and ORDER BY clauses
  7. Use aggregate functions like COUNT, AVG, SUM
  8. Understand how HTML, CSS, and SQL work together in web applications

💬 Discussion Prompts
  • "What happens if we remove the DOCTYPE? Let's test it!" (Explore quirks mode)
  • "Why do we need both margin AND padding?" (Box model understanding)
  • "What could go wrong if we run UPDATE without a WHERE clause?" (SQL safety)
  • "How would Facebook use SQL to show your friends' posts?" (Real-world relevance)
  • "What data types does SQL support? What about JavaScript?" (Type systems)
🔧 Troubleshooting Common Issues
  • Database won't initialize: Check browser console. Usually a CDN loading issue. Have students refresh.
  • "My SQL query doesn't work!" Check for: missing quotes around strings, typos in table/column names, missing WHERE in UPDATE/DELETE.
  • CSS not applying: Check selector specificity. Use DevTools to see which rules are being overridden.
  • Form won't submit: preventDefault() is used for demo purposes. Explain that real forms send data to servers.
🎓 Differentiation Strategies
  • Struggling students: Pair with peers, focus on exercises 1-3, provide filled-in templates
  • Advanced students: Bonus exercises, ask them to build their own tables, introduce JOINs, teach responsive design
  • Students who like to see it first: Lead with DevTools, the box model diagram, and colour pickers
  • Kinesthetic learners: Have them physically draw tables on paper, use manipulatives for box model
