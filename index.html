Part 1: HTML Basics

Getting started

Read an example, then try it. Whenever you wonder "what would happen if I changed this?", change it and see. That question is most of how programmers learn.

What is HTML?

HTML (HyperText Markup Language) is the standard language for creating web pages. It uses tags to structure content.

HTML Structure Example:

<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is a paragraph.</p>
</body>
</html>

Common HTML Tags:

  • <h1> to <h6> - Headings (h1 largest, h6 smallest)
  • <p> - Paragraph
  • <a href="url"> - Link
  • <img src="image.jpg" alt="description"> - Image
  • <div> - Container/division
  • <span> - Inline container
  • <ul> and <li> - Unordered list
  • <table>, <tr>, <td> - Table elements

Part 2: CSS Styling

Getting started

You can change the CSS of any web page, including this one. Right-click something on the page and choose Inspect. The panel that opens is the browser's DevTools (developer tools), and it shows the CSS for whatever you clicked. Click a value, such as a colour, and type a new one. Nothing you change there is saved, so experiment freely: refreshing the page puts everything back.

What is CSS?

CSS (Cascading Style Sheets) controls how HTML elements look on the page: colours, fonts, layouts, and more.

A spelling note: CSS uses American spelling, so the property is color, never colour. If you write colour: red; the browser quietly ignores it. No error, just nothing happens.

Three Ways to Add CSS:

  1. Inline: <p style="color: blue;">Text</p>
  2. Internal: In <style> tags within <head>
  3. External: Separate .css file (Best practice!)

CSS Syntax:

selector {
    property: value;
    another-property: value;
}

/* Example: */
p {
    color: blue;
    font-size: 16px;
    margin: 10px;
}

CSS Selectors

  • element - Selects all elements of that type (e.g., p)
  • .class - Selects elements with that class (e.g., .highlight)
  • #id - Selects element with that ID (e.g., #header)
  • element.class - Combines selectors (e.g., p.intro)

Try It: Restyle This Page

The Appearance button (top right, or bottom right on a phone) changes how this page looks. Open it, switch to the dark theme, then try a different font or a bigger text size.

The HTML stays exactly the same when you do this. The page keeps its colours and sizes in CSS variables: values with a name, such as --bg for the background colour. The Appearance panel swaps in a different set of values. Here is a small piece of this page's own styles.css:

:root {
    --bg: #f5f7fa;
    --fg: #1f2933;
}

:root[data-theme="dark"] {
    --bg: #12151c;
    --fg: #e6e8eb;
}

body {
    background-color: var(--bg);
    color: var(--fg);
}

Something to notice: the body rule never mentions dark mode. It only asks for var(--bg). Which rule decides what --bg is, and when?

What is SQL?

SQL (Structured Query Language) is used to manage and query databases. It lets you store, retrieve, update, and delete data.

Our Sample Database: Students & Courses

We've created two tables for you to practise with:

  • students - Contains student information (id, name, age, grade)
  • courses - Contains course information (id, name, instructor, credits)
Initializing database...

Basic SQL Commands

SELECT - Retrieve Data

SELECT column1, column2 FROM table_name;

Gets data from a table. Use * to select all columns.

WHERE - Filter Results

SELECT * FROM students WHERE age > 20;

Keeps only the rows that match a condition. Try it: only three of the eight students are over 20.

ORDER BY - Sort Results

SELECT * FROM students ORDER BY name ASC;

Sorts results. Use ASC (ascending) or DESC (descending).

INSERT - Add New Data

INSERT INTO students (name, age, grade) 
VALUES ('John', 20, 85);

Adds new rows to a table.

UPDATE - Modify Data

UPDATE students SET grade = 90 
WHERE name = 'John';

Changes existing data. Always use WHERE!

DELETE - Remove Data

DELETE FROM students WHERE id = 5;

Removes rows from a table. Use carefully!

Practice Exercises

These exercises progress from simple to complex. You can:

  • Work through them in order to build skills progressively
  • Choose exercises that match your current comfort level
  • Open the hint first. If you're still stuck, open the answer, then close it and try writing the query yourself
  • Come back to challenging exercises after completing easier ones

Learning Tip: If you get an error, read it carefully. SQL error messages often tell you exactly what's wrong.

Exercise 1: Basic SELECT

Select only the name and age columns from the students table.

Show hint

Use: SELECT column1, column2 FROM table_name;

Show answer 
SELECT name, age FROM students;

You should see 8 rows with just two columns, name and age.

Exercise 2: WHERE Clause

Find all students whose grade is less than 75.

Show hint

Use the WHERE clause with the < (less than) operator.

Show answer 
SELECT * FROM students WHERE grade < 75;

You should see one student: Frank Miller, with 73. Carol Williams has 76, so she just misses out.

Exercise 3: INSERT

Add yourself as a new student to the database!

Show hint

Start with INSERT INTO students (name, age, grade) VALUES (...); Text goes inside quotes, numbers don't. You don't need to give an id.

Show answer 
INSERT INTO students (name, age, grade) VALUES ('Your Name', 20, 85);

Put your own name inside the quotes. The playground should say 1 row changed. To see yourself, run SELECT * FROM students; and look at the last row. You never gave an id: the database numbered you itself.

Exercise 4: Sorting

Show all students sorted by name in alphabetical order.

Show hint

Use ORDER BY with ASC for ascending order.

Show answer 
SELECT * FROM students ORDER BY name ASC;

ASC is the default, so ORDER BY name gives the same result. Swap ASC for DESC to reverse the order.

Exercise 5: COUNT Function

How many courses are in the database?

Show hint

Use: SELECT COUNT(*) FROM table_name;

Show answer 
SELECT COUNT(*) AS total_courses FROM courses;

You should see 5. The AS total_courses part is optional: it gives the result column a readable name.

Challenge Exercises

Ready for more? These combine what you've learned in new ways. Some of them change the data: the Reset Database button puts everything back.

Exercise 6: UPDATE

Give every student with a grade below 75 a 5-point bonus.

Show hint

UPDATE students SET grade = ... WHERE ...; A column can use its own value, as in grade + 5.

Show answer 
UPDATE students SET grade = grade + 5 WHERE grade < 75;

The playground should say 1 row changed: Frank Miller goes from 73 to 78.

Exercise 7: DELETE

Remove every student under the age of 20.

Show hint

DELETE FROM students WHERE ...; Before you delete, run SELECT * with the same WHERE to see exactly which rows you are about to remove.

Show answer 
DELETE FROM students WHERE age < 20;

2 rows changed: Bob Smith and Frank Miller, who are both 19. Press Reset Database to bring them back.

Exercise 8: Combining Conditions

Find the students aged 20 or 21 with a grade above 85, highest grade first.

Show hint

Join conditions with AND and OR. Brackets decide which part is worked out first, just as in maths.

Show answer 
SELECT * FROM students
WHERE (age = 20 OR age = 21) AND grade > 85
ORDER BY grade DESC;

Henry Moore (94), Grace Wilson (89) and Alice Johnson (88). David Brown is 20, but his grade is exactly 85, and above 85 means more than 85.

Exercise 9: Average

What is the average grade of the students aged 20?

Show hint

AVG(column) works like COUNT(*), but gives the average of the values instead of counting them.

Show answer 
SELECT AVG(grade) AS average_grade FROM students WHERE age = 20;

89, the average of Alice (88), David (85) and Henry (94). If you added yourself aged 20 in Exercise 3, you're included too, so your number will be different.

Exercise 10: The Other Table

Find all the courses worth 4 credits.

Show hint

The same pattern as Exercise 2, on the courses table.

Show answer 
SELECT * FROM courses WHERE credits = 4;
