How they work together

Think of a login page:

  • HTML creates the form: a box for your username, a box for your password, and a button
  • CSS decides how the form looks: its colours, fonts and spacing
  • SQL looks up your username in a database, and checks your password against a hashed (scrambled, one-way) copy of it. Well-built sites never store your actual password.

Part 1: HTML basics

Getting started

Read an example, then try it. Whenever you wonder "what would happen if I changed this?", change it and see. That question is most of how programmers learn.

What is HTML?

HTML (HyperText Markup Language) is the standard language for creating web pages. It uses tags to structure content.

An HTML page

<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is a paragraph.</p>
</body>
</html>

Common HTML tags

  • <h1> to <h6>: headings (h1 is the largest, h6 the smallest)
  • <p>: a paragraph
  • <a href="url">: a link
  • <img src="image.jpg" alt="description">: an image
  • <div>: a container (division) that groups things
  • <span>: a container inside a line of text
  • <ul> and <li>: a bulleted (unordered) list
  • <table>, <tr>, <td>: a table, its rows and its cells

HTML forms

Forms collect information from the person using the page. Try this one:

The HTML for this form

<form>
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>
    
    <label for="age">Age:</label>
    <input type="number" id="age" name="age" min="1" max="120">
    
    <button type="submit">Submit</button>
</form>

Part 2: CSS styling

Getting started

You can change the CSS of any web page, including this one. Right-click something on the page and choose Inspect. The panel that opens is the browser's DevTools (developer tools), and it shows the CSS for whatever you clicked. Click a value, such as a colour, and type a new one. Nothing you change there is saved, so experiment freely: refreshing the page puts everything back.

What is CSS?

CSS (Cascading Style Sheets) controls how HTML elements look on the page: colours, fonts, layouts, and more.

A spelling note: CSS uses American spelling, so the property is color, never colour. If you write colour: red; the browser quietly ignores it. No error, just nothing happens.

Three ways to add CSS

  1. Inline: <p style="color: blue;">Text</p>
  2. Internal: In <style> tags within <head>
  3. External: a separate .css file. This is the usual choice, and the one this page uses.

CSS syntax

selector {
    property: value;
    another-property: value;
}

/* Example: */
p {
    color: blue;
    font-size: 16px;
    margin: 10px;
}

CSS selectors

  • element: every element of that type, for example p
  • .class: every element with that class, for example .highlight
  • #id: the one element with that id, for example #header
  • element.class: both at once, for example p.intro

The box model

Every HTML element is a rectangular box, built in layers from the inside out:

Margin
Border
Padding
Content

CSS exercise 1: Colour and corners

Make the card green, with rounded corners.

Show hint

background-color takes a colour name, like lightgreen, or a hex code, like #c8f7c5. Rounded corners come from border-radius.

Show answer 
.card {
  background-color: lightgreen;
  padding: 10px;
  border: 2px solid green;
  border-radius: 12px;
}

The bigger the border-radius, the rounder the corners. Try 50px.

CSS exercise 2: Room to breathe

Give the card more space inside its border, and more space around the outside of it.

Show hint

Look back at the box model: padding is the space inside the border, margin is the space outside it.

Show answer 
.card {
  background-color: lightyellow;
  padding: 24px;
  margin: 30px;
  border: 2px solid gray;
}

Padding pushes the text away from the border. Margin pushes the whole card away from everything else.

CSS exercise 3: A second rule

Change the heading's colour and font, and centre all the text in the card.

Show hint

Write a second rule whose selector is h2. The properties you need are color, font-family and text-align. Remember: color, not colour!

Show answer 
.card {
  background-color: lightyellow;
  padding: 10px;
  border: 2px solid gray;
  text-align: center;
}

h2 {
  color: darkblue;
  font-family: Georgia, serif;
}

text-align goes on .card because it affects everything inside the card. The h2 rule affects only the heading.

Try it: restyle this page

The Appearance button, at the right-hand end of the bar at the top of the screen, changes how this page looks. Open it, switch to the dark theme, then try a different font or a bigger text size.

The HTML stays exactly the same when you do this. The page keeps its colours and sizes in CSS variables: values with a name, such as --bg for the background colour. The Appearance panel swaps in a different set of values. Here is a small piece of this page's own styles.css:

:root {
    --bg: #f5f7fa;
    --fg: #1f2933;
}

:root[data-theme="dark"] {
    --bg: #12151c;
    --fg: #e6e8eb;
}

body {
    background-color: var(--bg);
    color: var(--fg);
}

Something to notice: the body rule never mentions dark mode. It only asks for var(--bg). Which rule decides what --bg is, and when?

Part 3: SQL database queries

Getting started

Read the commands first, or jump straight to the playground and click an example query. Both work. The database starts fresh every time you refresh the page, so you can't break anything permanently.

What is SQL?

SQL (Structured Query Language) is used to manage and query databases. It lets you store, retrieve, update, and delete data.

The sample database

We've created three tables for you to practise with:

  • students: one row per student (id, name, age, grade)
  • courses: one row per course (id, name, instructor, credits)
  • enrolments: which student takes which course (id, student_id, course_id). You'll use this one at the end, in Connecting tables with JOIN

Forgotten a column name? The Show Tables button in the playground lists every table and its columns.

Starting the database...

Basic SQL commands

SELECT: get data

SELECT column1, column2 FROM table_name;

Gets data from a table. Use * to get every column.

WHERE: keep only some rows

SELECT * FROM students WHERE age > 20;

Keeps only the rows that match a condition. Try it: only three of the eight students are over 20.

ORDER BY: sort the results

SELECT * FROM students ORDER BY name ASC;

Sorts the results: ASC for ascending (A to Z, small to big), DESC for descending.

INSERT: add rows

INSERT INTO students (name, age, grade) 
VALUES ('Sam', 20, 85);

Adds a new row to a table.

UPDATE: change rows

UPDATE students SET grade = 90 
WHERE name = 'Sam';

Changes existing rows. Without a WHERE, it changes every row.

DELETE: remove rows

DELETE FROM students WHERE id = 5;

Removes rows. Without a WHERE, it removes every row.

SQL exercise 3: INSERT

Add yourself as a new student to the database!

Show hint

Start with INSERT INTO students (name, age, grade) VALUES (...); Text goes inside quotes, numbers don't. You don't need to give an id.

SQL exercise 4: Sorting

Show all students sorted by name in alphabetical order.

Show hint

Use ORDER BY with ASC for ascending order.

Show answer 
SELECT * FROM students ORDER BY name ASC;

ASC is the default, so ORDER BY name gives the same result. Swap ASC for DESC to reverse the order.

How many courses are in the database?

Show hint

SQL exercise 8: Combining conditions

Find the students aged 20 or 21 with a grade above 85, highest grade first.

Show hint

Join conditions with AND and OR. Brackets decide which part is worked out first, just as in maths.

WHERE (age = 20 OR age = 21) AND grade > 85

What is the average grade of the students aged 20?

Introduction to Programming and Database Systems.

Connecting tables with JOIN

So far each query has used one table. The third table, enrolments, connects the other two: each row says that one student takes one course. It doesn't store any names, only numbers that point at rows in the other tables.

  • student_id matches an id in students
  • course_id matches an id in courses

A column that points at another table like this is called a foreign key. To see the names instead of the numbers, you JOIN the tables: you tell the database which columns should match, and it puts the matching rows side by side.

Example: each enrolment with the student's name

SELECT students.name, enrolments.course_id
FROM enrolments
JOIN students ON students.id = enrolments.student_id;

Read the ON line as "match each enrolment to the student whose id is the same as its student_id". Writing students.name instead of just name says which table the column comes from, which matters once two tables both have a column called name.

SQL exercise 11: Who takes what

List every student next to the name of each course they take.

Show hint

Start FROM enrolments, then JOIN students and JOIN courses, each with its own ON. Both tables have a name column, so use AS to give them different names in the results.

Show answer 
SELECT students.name AS student, courses.name AS course
FROM enrolments
JOIN students ON students.id = enrolments.student_id
JOIN courses ON courses.id = enrolments.course_id;

You should see 13 rows. Some students appear more than once, because they take more than one course. If you see fewer, you probably deleted Kwame and Wei in Exercise 7: press Reset Database and run it again.

SQL exercise 12: One course

Who takes Web Development?

Show hint

Take your answer to Exercise 11 and add a WHERE on the course's name. Text goes in single quotes.

Show answer 
SELECT students.name AS student
FROM enrolments
JOIN students ON students.id = enrolments.student_id
JOIN courses ON courses.id = enrolments.course_id
WHERE courses.name = 'Web Development';

Aoife Murphy, Priya Sharma and Dmytro Kovalenko.

SQL exercise 13: Nobody home (hardest)

Which student isn't enrolled in any course?

Show hint

A plain JOIN only keeps rows that match, so a student with no enrolments disappears. A LEFT JOIN keeps every student and leaves the enrolment columns empty (NULL) where nothing matched. Then keep only the rows where the enrolment is NULL.

Show answer 
SELECT students.name
FROM students
LEFT JOIN enrolments ON enrolments.student_id = students.id
WHERE enrolments.id IS NULL;

Wei Chen. If you added yourself in Exercise 3, you'll appear too, since you haven't enrolled in anything. If you deleted Wei in Exercise 7, press Reset Database first.
